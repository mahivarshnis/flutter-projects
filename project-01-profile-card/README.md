# Flutter Profile Card App

## About
A simple profile card application built using Flutter and Dart.

## Features
- Profile avatar with initials
- Name and role display
- Email, phone and location details
- Reusable ContactRow widget
- Responsive layout using ConstrainedBox
- Customized Material 3 theme

## Technologies Used
- Flutter
- Dart
- Material Design 3

## What I Learned
- Flutter widget tree
- Row and Column layouts
- Container, Card and Padding
- StatelessWidget
- Reusable widgets
- Responsive UI design
